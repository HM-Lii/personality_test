# 历史人物证据链方法

`figure-evidence.json` 用来回答一个可追溯的问题：

> 为什么这位历史人物会被放在某些关键叙事维度上？

它不是古人的心理测量档案，也不证明人物具有某种稳定的现代人格。每条记录只建立一条可审查的推断链：

```text
历史事件
  → 可定位的史料或传记来源
  → 对 O / C / E / A / R 中一个关键维度的解释
  → 证据可信度与理由
  → 可能存在的材料、动机或解释争议
```

## 数据结构

每位人物至少覆盖两个不同的关键维度，每个维度至少有一条完整证据链：

```json
{
  "id": "zhuge-liang",
  "evidenceChains": [
    {
      "dimension": "C",
      "event": "入蜀后主持政务、法令与后勤，并在北伐中持续组织远征。",
      "source": {
        "title": "《三国志》及裴松之注",
        "kind": "纪传体史书与早期注引",
        "url": "https://zh.wikisource.org/wiki/三國志",
        "locator": "卷35《蜀书·诸葛亮传》"
      },
      "interpretation": "长期维持行政与军事计划，可支持极高结构执行（C）。",
      "confidence": {
        "level": "high",
        "reason": "有本人著述、同时代记录或多项可核事实支撑；维度映射仍是现代解释。"
      },
      "controversy": "《三国志》对其治政评价很高，但北伐成效和法政代价历来有争论。"
    }
  ]
}
```

## 来源优先级

1. 本人著述、日记、书信、奏疏等第一人称材料；
2. 同时代或较接近时代的记录；
3. 正史、编年史和严肃传记；
4. 后出笔记、轶事与文学传统。

后两类材料不能自动排除，但必须在 `confidence` 和 `controversy` 中说明成书年代、修史立场、文学加工或归属争议。电子文本主要链接到[中国哲学书电子化计划](https://ctext.org/zh)、[维基文库古籍](https://zh.wikisource.org/wiki/Portal:古文)与[CBETA](https://cbetaonline.dila.edu.tw/)；链接用于定位原文，不代表平台对本项目的维度解释背书。

## 可信度等级

- `high`：有本人材料、近时记录或多项可核事实支撑；仍只代表“较强的叙事解释”。
- `medium`：基本事件可用，但细节、动机或评价明显受成书年代和修史立场影响。
- `low`：主要来自后出轶事、单一传统或文学化叙述，仅作为文化原型的弱证据。

可信度评价的是“材料能否支持这条维度解释”，不是人物的道德等级，也不是心理量表的信效度。

## 维护与校验

证据链的可编辑来源为 `scripts/build-figure-evidence.mjs`，运行后生成 `docs/figure-evidence.json`：

```powershell
npm run build:evidence
npm run validate
```

校验会强制检查：

- 人物库全覆盖且 ID 唯一；
- 每人至少两条证据链，覆盖至少两个不同关键维度；
- 事件、来源、定位、解释、可信度理由和争议均非空；
- 来源使用 HTTPS 且属于允许的古籍、档案或研究平台；
- 运行时 `FIGURES` 已正确注入对应证据链。
